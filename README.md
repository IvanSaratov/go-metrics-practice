# go-metrics-practice

Сервис сбора метрик: агент собирает runtime- и системные метрики, а сервер принимает и хранит их в файле или PostgreSQL.

## Быстрый запуск

```bash
docker compose -f infra/compose.yaml up --build
```

Сервер будет доступен на <http://localhost:8080>.

## Запуск локально

Нужен Go 1.26+. Запустите в разных терминалах:

```bash
go run ./cmd/server
go run ./cmd/agent
```

Параметры и переменные окружения: `go run ./cmd/server --help` и `go run ./cmd/agent --help`.

## Аудит запросов

Сервер может записывать события об успешно сохранённых метриках в файл и отправлять их по HTTP.

| Флаг | Переменная окружения | Назначение |
| --- | --- | --- |
| `--audit-file` | `AUDIT_FILE` | Путь к файлу аудита |
| `--audit-url` | `AUDIT_URL` | Полный URL приёмника |

Приёмники включаются независимо. Если указаны оба параметра, каждое событие передаётся в оба приёмника. Флаг имеет приоритет над переменной окружения, в том числе при явно пустом значении.

При остановке сервер даёт активным запросам до 5 секунд на завершение. После таймаута соединения закрываются, а ресурсы аудита освобождаются после выхода обработчиков.

## Статический анализ

Из корня проекта:

```bash
go run ./cmd/staticlint ./...
```

Команда запускает стандартные проверки Go, все проверки Staticcheck,
коастомные `bodyclose`, `nilerr` и нашу проверку запрета в `main`.

Инструкция по сборке, выбору проверок и описание каждого анализатора:

```bash
go doc ./cmd/staticlint
```
